What this is, and what it isn't

What it is
A flight recorder and canary lab for agent context compaction. It records what is in the window at every step, what compaction dropped, and whether the agent acts differently afterwards.
What it isn't
Not a new compaction algorithm, an observability platform, a leaderboard or a framework for building agents. It makes no new claims: the first experiment replicates published work on our own harness, and a null result is a valid outcome.
Where the data comes from
Everything on this page is a synthetic fixture: generated test data used to build the recorder. Recorded runs replace it at the next milestone, and every figure will link to the run file it came from.
