How it works.

Canary is a test kit for the moment an agent's context gets compacted. It plants a rule, lets the window fill, compacts it with the policy you want to test, and then watches what the agent does next. No judge model decides anything: the agent's own tool call is the evidence.

Four beats


          

        

      

    


    

      
How a run is judged

      

        

          
The grade

          
The agent answers the request with one tool call, and code reads its arguments. Posting to the channel the rule named is followed; any other channel is broken. Spacing, case, quotes and dash characters do not change a grade; a different channel does.

        

        

          
The conditions

          
Every seed runs four ways. Floor: the rule is never given, so the agent can only guess. Control: full context, nothing compacted. Length-matched: no compaction, but the history trimmed to the compacted size, which separates a shorter window from a damaged one. Treatment: the policy compacts, then the request.

        

        

          
Did the rule survive?

          
A second, mechanical check: is the planted channel name still in the window the agent saw when the request arrived? A reworded rule that still names the channel counts as kept, which is how most summaries keep it; a summary that never names it counts as gone. Summaries from the first experiment were also read by hand, and each later experiment gets a blind audit: the reader sees the summary and the rule, never the grade.

        

        

          
Uncertainty

          
Every rate comes with a 95% Wilson interval. The same seeds run under every condition, so comparisons are paired: only seeds where two conditions disagree count toward a difference, tested exactly.

        

        

          
Labels on every figure

          
recorded real model output, replayable from committed recordings. simulated real policy code run in your browser, no model. deterministic real policy code on seeded histories, no model. synthetic fixture generated test data.

        

      

    


    

      
Run it yourself

      
Everything here replays offline from the recordings in the repository. Live runs use free models only and refuse anything that is not provably free.

      

    


    

      
What this cannot tell you

      
    
        
  • A planted rule in a synthetic history is not a rule from a real organisation. The results are about arbitrary rules.
    • 
        
  • The history before the request is scripted, and the harness compacts once. Real sessions compact over and over.
    • 
        
  • The rule is planted near the start of the history. Policies that keep the opening turns keep it by construction; a rule planted mid-session is a different test.
    • 
        
  • The model that writes the summary is the model that acts on it.
    • 
        
  • Free models change and disappear. Every result names the model and the date.
    • 
        
  • Small samples: the intervals are wide on purpose, and say so.
    • 
        
  • One trial per seed. The seeds vary the history; the model's own sampling variance is not measured separately.
    • 
        
  • "Kept" means the planted value is still written in the window. That is necessary for the agent to act on it, not sufficient: a summary can name a channel in the wrong role. Blind hand audits check this, and found the machine's check right where they disagreed.
    • 
        
  • Each experiment adjusts its own preregistered comparisons. Nothing is corrected across experiments, so read one experiment's result at a time.
    •

What is new here

          
Not a new finding about compaction. What is new is a kit you can point at your own policy and watch: a recorder, a lab, recorded runs anyone can replay, and intervals on everything. The first experiment found that the outcome depends on which model writes the summary; a preregistered rerun confirmed the effect where it appeared, with the confound that had clouded it removed. The second puts four policies side by side on the same rule and the same seeds. EXP-004 plants three facts at three depths, because with one early fact "keep the head" is safe by construction.
