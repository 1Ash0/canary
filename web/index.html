the protocol

Three steps. One answer.

Does your compaction policy destroy the instructions your agent was given? Canary answers with a number and an honest confidence interval.

01

PLANT

Inject a constraint or identifier early in the conversation — something the agent must act on when probed later. This is the canary.

canary = ConstraintCanary(
  tool="send_message",
  arg="channel",
  value="#ops-7"
)
02

COMPACT

Run the conversation through a compaction policy — recency truncation, summarization, or LLM compression. The canary may not survive.

result = recency_truncate(
  messages=session,
  budget=8_192  # tokens
)
# canary dropped? unknown until probe
03

PROBE

Ask the agent to act on the canary. Grade the emitted tool call: respected, violated, or not applicable. Aggregate with Wilson confidence intervals.

grade = grader.grade(
  tool_call=response,
  spec=canary
)
# "violated" | "respected"
