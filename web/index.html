What a result looks like

Each condition is run on the same ten seeds. For each one we report the rate at which the rule was broken and how sure that rate is. These ten trials are a mock: the shape of a real result, with no model behind it.

What this is, and what it isn't

What it is
A flight recorder and canary lab for agent context compaction. It records what is in the window at every step, what compaction dropped, and whether the agent acts differently afterwards.
What it isn't
Not a new compaction algorithm, an observability platform, a leaderboard or a framework for building agents (it runs a small agent loop only so that compaction can be tested). Its first experiment replicates published work on our own harness rather than claiming something new, and a null result is a valid outcome.
Where the data comes from
Everything on this page is a synthetic fixture or mock data: generated to build the recorder. Recorded runs replace it at the next milestone, and every figure links to the file it came from.
