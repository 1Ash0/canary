    What this is, and what it isn't

    What it is
    A flight recorder and canary lab for agent context compaction. It records what is in the window at every step, what compaction dropped, and whether the agent acts differently afterwards.
    What it isn't
    Not a new compaction algorithm, an observability platform, a leaderboard or a framework for building agents; the harness exists only to run test scenarios. Its first experiment tried to reproduce published work on our own harness and came out split between models. Every result is reported with its interval, nulls included.
    Where the data comes from
    The run, the comparison and the results above are recorded: real model output, replayable from committed recordings. The policy grid is deterministic: real policy code, no model. The recorder's sample run is a synthetic fixture. Every figure names the file it came from.
